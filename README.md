# Credit Risk Analysis Project

## Project Overview
This project analyzes customer credit data and predicts loan default risk using Machine Learning techniques.

## Dataset
Home Credit Default Risk Dataset

## Project Workflow
- Data Cleaning
- Exploratory Data Analysis (EDA)
- SQL Analysis
- Data Visualization
- Feature Engineering
- SMOTE for class balancing
- Random Forest Model
- Feature Importance Analysis

## Tools & Technologies
- Python
- Pandas
- NumPy
- SQL
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Model Performance
- Accuracy: 92%
- Precision: 90–94%
- Recall: 89–95%
- F1 Score: 92%

## Key Insights
- EXT_SOURCE_3 was among the most important features
- Class imbalance handled using SMOTE
- Random Forest achieved strong prediction performance
